# Week 1: Foundations

By Friday the mentee can explain what MLOps is, work in a Linux terminal and Git, and train and save a basic model in Python.

| Day | Topics to study | Hands-on task |
| --- | --- | --- |
| 1 | What MLOps is; the ML lifecycle (data → train → evaluate → deploy → monitor → retrain); DevOps vs MLOps; training vs inference | Write one page on the ML lifecycle in your own words, with a simple diagram of the stages |
| 2 | Linux and shell: files, navigation, permissions, processes, pipes, grep, environment variables, PATH, SSH | Set up Ubuntu or WSL; complete 30 commands from the topic list and save them in a notes file |
| 3 | Git and GitHub: clone, branch, commit, merge vs rebase, pull requests, merge conflicts, .gitignore | Create a branch out of this repo; create and resolve a merge conflict on purpose; open a PR |
| 4 | Python for ML: venv, pip, requirements.txt, functions, modules, pandas and NumPy basics | Pick the project dataset; load and explore it with pandas (shape, nulls, value counts) |
| 5 | ML basics: supervised vs unsupervised, classification vs regression, features and labels, train/test split, overfitting, accuracy, precision, recall, F1 | Train a scikit-learn classifier on the dataset, print metrics, save it with joblib |

Catch up on anything below 3; make sure the repo has the notes, the EDA notebook and the trained model script.
